# IndexTTS 2.5 Premium v6.1: Automatic Training Stop, Better Validation & New Voice Results

I’ve released v6.1 with improvements to LoRA/DoRA voice training, checkpoint selection, and dataset quality checks.

The main addition is **Automatically stop when progress stalls**, enabled by default. Training can stop before the requested epoch or step limit while preserving the best checkpoint. You can adjust the stopping settings or disable the checkbox when you want to run the full budget.

This update also brings:

- **More reliable validation:** complete recordings are held out by default, reference clips come from training data, and the full validation set is checked regularly.
- **More accurate training targets:** FP32 semantic feature extraction, with cache checks that detect changed audio, captions, and model assets.
- **Better checkpoint tracking and resume:** improvements between epochs are included, and the saved training state retains the best update and stopping counter.
- **Optional dataset and comparison tools:** collect main video/SRT pairs, screen speaker consistency and transcript agreement, and measure generated speech.
- Updated presets, help, documentation, and release notes inside Gradio’s **Changelog** tab.

I also completed a new V4 English voice experiment using **7.85 hours of curated training audio**, about **75% more than V3**. Training stopped automatically at update 10,250 and kept update 9,195 as the best checkpoint.

On a separate test recording, V4 achieved **3.28% lower predictive loss** than V3. Across twelve test prompts, ASR-measured word error fell from **6.83% to 5.69%**. These results reflect the combined dataset and pipeline changes; speaker/style scores were broadly similar, and automated measurements are not human listening ratings. The full verification generated **93 audio clips**.

**To update on Windows:** close the app, run `Windows_Install_or_Update.bat`, then start it with `Windows_Start_App.bat`. Open **Changelog** to read the v6.1 notes. For new training runs with existing datasets, run feature caching again to rebuild older caches with the corrected extractor.
